# 概要設計書_134_インジケーターテンプレート取得(TV)

## 処理概要

---

APIは、インジケーターテンプレートの情報を取得する。

   1. リクエスト情報（「インジケータテンプレート名」）を受け取る

   2. 「TVインジケーターテンプレートマスタ」を「インジケータテンプレート名」を条件に取得する

      「インジケータテンプレート名」、「インジケータテンプレートの内容」を取得（「インジケーターテンプレートDTO」）する。

   3. レスポンス情報（「インジケーターテンプレートDTO」）を返す

リクエストとレスポンスのプロパティ等は、別紙「Peach API」を参照。

## 処理詳細

1. token 認証

   トークンの有効性を確認する。

   補足資料「S-01.ログイン状態チェック」を参照。

2. バリデーション確認

   | パラメータ | 必須 | 長さ | 範囲 | 形式(型、メール等) | メモ |
   |------------|------|------|------|--------------------|------|
   | name       | x    | 64   | -    | 文字               |      |

   エラーの場合は、ステータスコード(`422`)、メッセージ（`CODE:30020`）を返す。

3. インジケーターテンプレート取得

   [1]から以下の条件で取得（「インジケーターテンプレート」）する。

   - 「顧客NO」がTokenの顧客NOと一致する。

   - 「インジケータテンプレート名」はパラメータの「name」と一致する。

   データが取得できない場合は、ステータスコード(`404`)、メッセージ（`CODE:30404`）を返す。

4. 「インジケーターテンプレート」を「インジケーターテンプレートDTO」にマッピングし

   | インジケーターテンプレートDTO | 「インジケーターテンプレート」の値   | 説明                           |
   |-------------------------------|--------------------------------------|--------------------------------|
   | name                          | [1]の「インジケータテンプレート名」  | インジケータテンプレート名     |
   | content                       | 同「インジケータテンプレートの内容」 | インジケータテンプレートの内容 |

   「インジケーターテンプレートDTO」をレスポンスとして返す。
